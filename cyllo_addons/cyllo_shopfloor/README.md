Cyllo Shop Floor
----------------

The Cyllo <a href="https://www.cyllo.com/shopfloor">Shop Floor</a> app gives operators
a tablet-friendly interface to run manufacturing work orders in real time, organised
by work center and connected live to the backend.

Work Center Interface
---------------------

Browse work orders grouped and filtered by state within each work center, with
dashboard metrics that summarise how many operations are in progress, completed, or
canceled per work center.

Operator Assignment
------------------

Select the employee working on an operation so that starting a work order records the
operator on the manufacturing order, giving clear visibility of who did what.

Live Synchronisation
--------------------

State changes are broadcast over a dedicated bus channel so the shop floor screen and
the backend stay in sync as work orders are started, paused, blocked, or finished.

Automated Operations
--------------------

Mark a bill of materials or manufacturing order as automated so a scheduled job starts
and finishes work orders once their expected duration elapses, then closes the order
automatically once all operations are done.

Component and Work Order Wizards
--------------------------------

Quick wizards let operators add or scrap components, add custom work orders on the fly,
and reroute a work order to a different work center directly from the floor.

One-Click Order Completion
--------------------------

Close a manufacturing order from the shop floor in a single action that fills in
tracking, quantities, and component consumption, while missing components are
calculated and surfaced to the operator.
