Cyllo Access Management
-----------------------

The Cyllo <a href="https://www.cyllo.com/access-management">Access Management</a> app is an all-in-one
access manager that lets you control exactly what each user can see and do. Group users into reusable
profiles and layer on menu, button, tab, filter, field, model and record-level restrictions from a single
place, without writing code.

User Profiles
-------------

Create user profiles that bundle a set of Cyllo security groups and assign them to internal users.
Adding or removing a user from a profile automatically synchronises the corresponding group memberships,
so onboarding and role changes stay consistent across the database.

Profile Management Rules
------------------------

Each Profile Management record links one or more profiles to a configurable set of restrictions and can be
scoped to specific companies or activated and deactivated at will. From here you can make the whole system
read-only, disable the chatter on documents, block developer debug mode, or even prevent selected profiles
from logging in.

Menu, Button and Tab Control
----------------------------

Hide entire menu items from users in a profile, and suppress individual buttons or notebook tabs on form
views. The hidden elements are injected as invisible at view-rendering time, keeping restricted actions out
of reach for the targeted profiles.

Filter and Field Access
------------------------

Remove search-view filters and grouping options, and control fields on a case-by-case basis by making them
readonly, invisible or required, or by stripping the external open/create links from relational fields. Each
field rule can carry an optional domain so the restriction applies only when a record meets the condition.

Model-Level Access
------------------

Apply per-model restrictions that make a model read-only or hide its Create, Edit, Delete, Archive,
Duplicate, Export, Report and contextual Action options. This gives you fine-grained control over the
operations available on any Cyllo model, per profile.

Domain-Based Record Access
--------------------------

Attach record-level domains to a model so users in a profile only ever see the records that match your
criteria. The domain is merged into every search on that model, delivering true row-level data isolation
across list, form and kanban views.
