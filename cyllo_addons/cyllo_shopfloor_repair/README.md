Cyllo Repair Floor
------------------

The Cyllo <a href="https://www.cyllo.com/shopfloor-repair">Repair Floor</a> app provides
a tablet-friendly interface for repair technicians, bringing repair orders onto a
dedicated dashboard built for touch-based work on the floor.

Repair Floor Dashboard
----------------------

Open a repair order directly on the Repair Floor dashboard, where repair cards present
the work to be done in a clean, touch-oriented layout for technicians.

Card-Based Workflow
------------------

Repair work is presented through interactive repair cards, giving technicians a focused
view of each order and its lines without navigating the full backend form.

Repair Notes
-----------

View and capture notes for a repair order through a dedicated popup, keeping relevant
observations and instructions close at hand during the repair.

Edit Repair Lines
----------------

A wizard lets technicians adjust the products, quantities, and units of measure on a
repair line quickly, so parts used can be corrected as the repair progresses.

Repair Integration
------------------

Built on top of the Cyllo Repair application, the Repair Floor extends existing repair
orders rather than replacing them, so floor activity stays consistent with backend records.
